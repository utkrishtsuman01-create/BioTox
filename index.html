Good science matters

Questions worth asking

A prediction is only as useful as the evidence and limitations behind it.

Does this website currently run a trained ML model?

No. This repository currently contains a front-end prototype. The interactive report is explicitly illustrative; it is not generated by a trained or validated model. A real model and backend API must be integrated before scientific predictions can be claimed.

What is a SMILES string?

SMILES (Simplified Molecular Input Line Entry System) is a text notation used to represent a molecular structure. A production system should validate the string with a chemistry toolkit such as RDKit before generating model features.

Can this result determine whether a chemical is safe?

No. Computational predictions can support preliminary research, but they do not replace laboratory testing, exposure assessment, regulatory review, or qualified toxicological judgment.

What is needed to make predictions scientifically meaningful?

A documented dataset, defined toxicity endpoint and labels, a reproducible training/evaluation pipeline, independent test data, appropriate metrics, applicability-domain checks, and a secure model-serving API. Report uncertainty and known limitations.
